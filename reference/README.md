# reference/

시뮬레이션 파라미터/물리 모델 선택의 근거로 삼을 참고 논문(PDF 등)을 넣어두는 곳.
매뉴얼(`manual/`)은 SDEVICE/SDE의 문법과 모델 옵션이 무엇인지 알려주지만,
"이 트랩 준위·단면적·농도 값을 왜 이렇게 잡았는지" 같은 물리적 근거는 여기 논문을
따라간다.

## 사용 규칙

- 논문 PDF를 파일명만으로 구분하기 어려우므로, 가능하면 `저자연도_짧은제목.pdf` 형식으로
  저장한다 (예: `Kim2019_CTN_trap_energy.pdf`).
- 커맨드에서 특정 파라미터(트랩 에너지 레벨, 단면적, 이동도 모델 계수 등)를 논문 값에
  맞춰 설정했다면, 관련 `runs/<실험명>/000N_*.md` 파일이나 커맨드 파일 주석에 어떤 논문의
  어떤 값을 썼는지 짧게 남긴다 — 나중에 왜 이 값을 썼는지 추적할 수 있도록.
- PDF가 많아지면(수십 페이지 이상) 매뉴얼처럼 전체를 미리 md로 옮기지 말고, 필요할 때
  `Read` 툴의 `pages` 파라미터로 관련 부분만 그때그때 확인한다.
