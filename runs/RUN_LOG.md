# 시뮬레이션 실행 이력 (RUN LOG) — 전체 실험 공통 인덱스

실험(주제)별로 `runs/<실험명>/000N_짧은설명.md` 파일에 기록하고, 여기에는 실험을
가로질러 한 줄씩 인덱스만 남긴다. 새 런을 만들 때는 `runs/TEMPLATE.md`를 복사해서
해당 실험 폴더 밑에 시작한다. 새 실험을 시작하면 `runs/<실험명>/` 폴더를 새로 만든다
(현재: `nand_pgm_EPEP`).

사용자가 "이번엔 이런 현상이 나왔어" 라고 알려주면:
1. 관련된 이전 RUN이 있으면 그 파일을 찾아 이어서 기록(원인 분석/수정/결과 갱신).
2. 없으면 해당 실험 폴더에 새 RUN 파일을 만들고 아래 표에 행을 추가한다.
3. 원인이 "명령 문법을 잘못 씀(환각)" 때문이었다면 `knowledge/PITFALLS.md`에도 반드시 기록한다.
