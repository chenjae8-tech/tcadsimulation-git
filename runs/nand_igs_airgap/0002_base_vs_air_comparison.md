# RUN 0002 — NAND_BASE vs NAND_AIR PGM 비교 (0001의 본 목적 수행)

- **날짜**: 2026-11-10
- **사용된 데이터**: `NAND_BASE/NAND_BASE_pgm_{s0vt,pulse,s1vt}_NAND_BASE_pgm_des.plt`
  (2026-11-03 17:08 KST 완주, 2026-11-10 scp로 윈도우에 재복사),
  `NAND_AIR/NAND_AIR_pgm_{s0vt,pulse,s1vt}_NAND_AIR_pgm_des.plt` (RUN 0001)
- **방법**: 두 `.plt`(DF-ISE text)의 `Info.datasets` 컬럼 구성이 동일함을 먼저 확인하고,
  awk로 Data 블록을 파싱해서 CSV화. Id-Vg(Drain TotalCurrent vs WL2 InnerVoltage)는
  로그전류 선형보간으로 Vt 추출(1e-9/1e-8/1e-7/1e-6 A/um). AIR 쪽 수치가 RUN 0001에
  기록된 값과 거의 일치해서(ΔVt 1e-7 기준 +3.350 vs 기존 기록 +3.350) 파싱 방법 검증됨.

## 결과

### 1) 선택 셀(WL2) 자체 포획 — pulse 끝(t=58us)

| | BASE | AIR |
|---|---|---|
| Sel eTrappedCharge | 2.1301e19 cm⁻³ | 1.8963e19 cm⁻³ |
| Tacc(1.003e20) 대비 점유율 | 21.24% | 18.91% |

BASE가 AIR보다 12.3% 더 많이 포획.

### 2) ΔVt (네 기준전류)

| 기준전류 | ΔVt(BASE) | ΔVt(AIR) |
|---|---|---|
| 1e-9 | +3.581 | +3.289 |
| 1e-8 | +3.615 | +3.323 |
| 1e-7 | +3.644 | +3.350 |
| 1e-6 | +3.677 | +3.383 |

BASE가 AIR보다 평균 ~0.3V 더 큰 ΔVt. (원인 미분석 — 메시/국소 필드 차이 가능성, 추가 조사 필요)

### 3) 이웃 셀 크로스토크 — pulse 끝(t=58us), 절대값

| 영역 | BASE | AIR |
|---|---|---|
| Pass_WL3 | 1.6254e16 | 1.6258e16 |
| Pass_WL1 | 1.6248e16 | 1.6253e16 |
| DSL | 1.6554e16 | 1.6556e16 |
| SSL | 1.6523e16 | 1.6526e16 |

**이웃 셀의 절대 포획량은 BASE·AIR 간 사실상 차이 없음.** Sel 대비 비율(BASE 1/1287~1311,
AIR 1/1145~1167)이 달라 보이는 건 분모(Sel 자체 포획량)가 달라서 생기는 산술적 효과일 뿐,
이웃 쪽 절대 수치 자체는 거의 그대로임.

## 해석

이번 단일 PGM 펄스 검증 테스트 구성에서는 WL_PASS/SG/DG가 자체적으로 방전/흔들리지 않는다
(`nand_pgm_erase_base` RUN 0002에서 확인된 크로스토크 메커니즘 — "discharge 이벤트의 채널
전위 변화" — 이 테스트엔 아예 없음). 즉 Air Gap이 억제해줄 만한 간섭 자체가 이 테스트
조건에서는 거의 발생하지 않을 가능성이 있다 — "Air Gap 효과 없음"이 아니라 "이 테스트가
Air Gap 효과를 볼 조건이 아닐 수 있음".

**사용자가 이전 세션(2026-11-03, 미기록)에서 언급한 "C2C 개선 효과가 없다"는 관찰과
이 결과가 동일한 현상일 가능성이 높음** — 사용자가 그때 참고 논문
(`reference/논문/Hole-Side_Airgap_Integration_as_Enabler_for_3D_NAND_Flash_Z-Pitch_Scaling.pdf`,
2026-11-03 16:40 추가, 아직 미분석)을 근거로 구조/테스트 수정이 필요하다고 했다는데 그
구체적 내용이 기록되지 않아 이번 세션에서 재확인 요청함. 아직 사용자 답변 대기 중.
